# Publicação nº 2 no LinkedIn: versão final

Ordem para postar:

1. `00-texto-artigo.txt`: texto completo, para publicar como artigo (passa de 3.000 caracteres). A primeira linha é o título.
2. `00-texto-feed.txt`: post curto para o feed (até 3.000 caracteres), apontando para o artigo.
3. `01-custo-acuracia.png`: custo × acurácia de todas as configurações, com a entregue (`api`) em destaque. Imagem principal.
4. `02-hubspot-note.png`: a qualificação gravada no HubSpot, com tier, critérios e justificativa.
5. `03-smoke-ponta-a-ponta.png`: o sistema completo em Docker, do `/health` ao registro no CRM.
6. `04-demo-offline.gif`: a demo que roda sem chaves e sem rede. O LinkedIn não mistura GIF com outras imagens no mesmo post: use no artigo ou num comentário.

Legenda sugerida para quem usar a GIF junto com os prints: o L024 aparece com score 95,0 na GIF (gravada em 23/10, prompt `v2`) e 100,0 nos prints (outras execuções). O tier é A nos dois.

Todos os números vêm de `evals/reports/`. As imagens são cópias de `docs/linkedin/`.
